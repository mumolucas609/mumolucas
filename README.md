## Featured Project

### Student Enrolment & Fee Analysis Dashboard

A practice project using a 135-record student dataset.

The work includes:

- Data cleaning and standardisation using Power Query.
- Data completeness checks and identification of missing information.
- Enrolment, gender, age and fee analysis using PivotTables and PivotCharts.
- A dashboard with formula-driven KPI cards and a data-completeness summary.

**Tools:** Microsoft Excel 2021, Power Query, PivotTables and PivotCharts.

The dataset was supplied for practice. Identifiable records and the original source workbook are not published.
